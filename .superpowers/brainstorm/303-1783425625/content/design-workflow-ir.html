设计 Part 1: Workflow IR 数据模型

这是前后端之间的契约——前端画布产出这份 JSON，后端编译器消费它生成 LangGraph StateGraph

核心概念层次

Workflow IR = Graph( Nodes + Edges ) + Schema + Metadata
层次 字段 说明
Metadata id, name, description, version, created_at 工作流元信息
Schema input_schema, output_schema, state_variables 工作流入参/出参/共享状态的 JSON Schema
Nodes[] id, type, label, position, config 节点列表，每个节点的 type 决定 config schema
Edges[] id, source, target, condition source→target 连线，可选 condition 做条件路由

MVP 节点类型 & 配置 Schema

🧠 LLM 节点

type: "llm"

config:
model, system_prompt, user_prompt (支持 {'{state.xxx}'} 模板), temperature, max_tokens

🔀 条件路由节点

type: "router"

config:
多条分支规则 (if/then/else)，出边各带 condition label

✋ 人工确认节点

type: "human_confirm"

config:
message (展示给用户的提示), timeout (超时默认动作), fields (待填写的表单字段)

⚡ 代码执行节点

type: "code"

config:
language (python/js), code (支持模板), timeout, env_vars

完整 IR 示例（简化）

一个 "需求分析 → LLM生成 → 人工审核 → 条件路由" 的工作流
{
  "id": "wf-001",
  "name": "AI代码生成管线",
  "version": "1.0",
  "schema": {
    "input_schema": { "requirement": "string", "component_lib": "string" },
    "state_variables": ["analysis_doc", "code", "review_comment"]
  },
  "nodes": [
    { "id": "n1", "type": "llm", "label": "需求分析", "position": {"x":100,"y":50},
      "config": { "model": "glm-5.2", "system_prompt": "你是需求分析师...", "user_prompt": "分析: {state.requirement}" } },
    { "id": "n2", "type": "llm", "label": "代码生成", "position": {"x":100,"y":200},
      "config": { "model": "deepseek-v4", "system_prompt": "你是Vue3工程师...", "user_prompt": "根据设计生成代码:\n{state.analysis_doc}" } },
    { "id": "n3", "type": "human_confirm", "label": "人工审核", "position": {"x":100,"y":350},
      "config": { "message": "请审核生成的代码", "fields": ["通过", "需要修改(请输入修改意见)"] } },
    { "id": "n4", "type": "router", "label": "判断结果", "position": {"x":100,"y":500},
      "config": { "branches": [ {"label":"通过","condition":"state.review_approved"}, {"label":"需修改","condition":"default"} ] } },
    { "id": "n5", "type": "code", "label": "格式化输出", "position": {"x":400,"y":500},
      "config": { "language": "python", "code": "import json\nresult = {'code': state['code']}\nreturn result" } }
  ],
  "edges": [
    { "id": "e1", "source": "n1", "target": "n2" },
    { "id": "e2", "source": "n2", "target": "n3" },
    { "id": "e3", "source": "n3", "target": "n4" },
    { "id": "e4", "source": "n4", "target": "n5", "condition": "通过" },
    { "id": "e5", "source": "n4", "target": "n2", "condition": "需修改" }
  ]
}
